判定方法说明

1. 严格口径（本页主口径）

  • 对每条预测，取该币种在 预测时间 + 10 分钟（或 +30 分钟）那一行 CSV 的价格作为结算价，容差 ±2.5 分钟内就近匹配；
  • 用 (结算价 − 预测价) / 预测价 判断真实方向：>0 为涨、<0 为跌；
  • 预测方向与真实方向一致才算赢，没有任何“波动太小算平/算赢”的豁免，这才是可交易的真实水平。

2. 原版规则 + 正确价格（口径 B）

  • 沿用 main.py 的判胜规则：方向一致 或 波动绝对值 < 0.02%（10 分钟）/ < 0.04%（30 分钟）都算赢；
  • 但结算价换成上面正确的时点价格。用于隔离「判平豁免」这一项的影响。

3. main.py 实际记录（口径 C）

  • 直接读取 CSV 中 backtest_10m / backtest_30m 列已有的 ✅ / ❌，即线上程序自己算出来的结果；
  • 它的结算价是「结算那一刻的实时价」，而非预测时刻 +10m/+30m 的时点价，且带判平豁免。

为什么三种口径会差这么多

如果 A 与 B 差距很大、B 与 C 接近，说明虚高的胜率主要来自「波动小判赢」的规则；如果三项都接近，说明价格结算方式无实质影响。本页顶部的结论横幅会自动给出该对比。

收益曲线的假设

  • 按预测方向开仓：看涨做多、看跌做空，持有到对应时点平仓；
  • 1 倍名义本金，逐笔累加（不复利），每笔扣除 2 × 手续费；手续费可在筛选栏调整，默认 0.04%/边（币安合约吃单档）；
  • 不含滑点、资金费率、强平，属于理想上界。
